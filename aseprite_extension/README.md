# PerfectPixel Aseprite 扩展插件

> **AI 像素画点阵逆向还原、对齐精修与色彩量化工具 —— Aseprite 原生插件**

---

## 🌟 功能特性

* **一键逆向还原 1:1 点阵**：将 Midjourney / DALL-E / Gemini 等 AI 生成的模糊抗锯齿“假大图”，精准还原为纯正的 1:1 像素画原稿。
* **智能梯度吸附对齐**：基于 Sobel 边缘梯度算法，自动纠正 AI 画面微小的色块畸变与不对齐。
* **原生 Aseprite 交互集成**：
  * 在 Aseprite 中选定图层或图片，随时唤起精修对话框。
  * 可选择 **“新建 Sprite 打开”** 或 **“作为新图层插入当前画布”**。
* **OKLab 色彩空间量化**：支持限制最大颜色数量（如 16 色、32 色），一键消除渐变杂色。
* **纯色背景快速剔除**：支持指定背景色与容差范围，自动转为透明通道。

## 📦 安装方法

### 方法一：双击一键安装（推荐）
1. 双击打包好的 `perfect-pixel-v1.0.0.aseprite-extension` 文件；
2. Aseprite 会自动弹窗询问是否安装该插件，点击 **“Enable” / “启用”** 即可！

### 方法二：在 Aseprite 内部手动载入
1. 打开 Aseprite，进入菜单栏：**Edit (编辑) $\rightarrow$ Preferences (首选项) $\rightarrow$ Extensions (扩展)**；
2. 点击右侧 **Add Extension (添加扩展)** 按钮；
3. 选择 `perfect-pixel-v1.0.0.aseprite-extension` 安装包；
4. 点击确定完成安装。

---

## 🚀 使用指南

1. **导入图片**：
   在 Aseprite 中打开任意像素风图片（如从 AI 工具下载的 2048×2048 像素大图）。
2. **启动插件**：
   点击顶栏菜单：**Edit (编辑) $\rightarrow$ PerfectPixel 像素精修...**。
3. **设置参数**：
   * **目标网格宽/高**：留 `0` 为全自动检测；若希望强制规整，可输入指定数值（如 `200`、`128` 等）。
   * **采样方式**：
     * `center`（中心取样）：保留最清晰的色彩中心。
     * `majority`（多数色）：适合保护细小轮廓线。
     * `median`（中位数）：过滤孤立噪点。
   * **最大颜色数**：限制调色板颜色总数，0 为不限制。
   * **输出目标**：
     * `新建 Sprite 打开 (推荐)`：生成全新的 1:1 原稿。
     * `作为新图层插入当前 Sprite`：在当前画布新增一个精修图层。
4. **点击【开始精修】**：
   后台自动执行极速精修计算，瞬间生成纯净点阵图！
